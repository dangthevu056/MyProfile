# MyProfile

A personal CV/portfolio page for Đặng Thế Vũ — Java Developer.

## Stack
- Pure HTML/CSS/JavaScript (single file: `profile.html`)
- Bootstrap 5.3 + Bootstrap Icons
- Google Fonts (Inter, Fira Code)
- No build step, no backend

## How to run
The `Profile` workflow serves the project with Python's built-in HTTP server:
```
python3 -m http.server 5000
```
Then open `/profile.html` in the preview.

## Project structure
- `profile.html` — entire CV page (styles, markup, JS all inline)
- `Avatar.jpg` — profile photo

## User preferences
- Language: Vietnamese (Tiếng Việt)
